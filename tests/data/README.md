# Test data

Committed fixtures used by the test suite and by the benchmark tools. Large
binary fixtures (`*.bin`) are generated and gitignored; their generator is
named below.

| file | used by | origin |
|---|---|---|
| `real_prompt.txt` | `tools/baseline/make_real_prompt.sh` (frozen workload prompt) | A one-time concatenation of SonicBoom's own docs and source (CLAUDE.md, backend HAL, Gemma 4 semantics, migration notes, plan/backend/elementwise/exec sources), frozen on 2026-10-22 as a byte-identical fixture so workload benchmarks stay comparable as the docs move (sha256 `31548eaa28c5e7572547a8cd5e3057c671e6bb97488c53f82bfcb94874f51f53`) |
| `real_prompt.tokens` | prefix-cache tests | `make_real_prompt.sh` output (first 9000 tokens) for the Gemma 4 GGUF; regenerating it must leave it byte-identical |
| `s-expr-v0-resnet18.example.sx` | S-Expr parser/executor and ONNX-importer tests | hand-written S-Expr rendering of ResNet-18 |
| `resnet18.weights.bin`, `resnet18.input.bin`, `resnet18.reference.bin` | the same tests | generated by `tools/reference/gen_resnet18_reference.py` from `models/resnet18.onnx` (gitignored) |
| `deepseek-r1-qwen15b/`, `qwen2/`, `train/` | model-specific goldens | recorded from the corresponding reference runs |

Anything that is engineering history, tuning notes, or experiment results
belongs in the private repo, not here.
